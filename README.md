# نظام تشغيل الأكاديمية — AI Workforce OS

**العمل:** أكاديمية أونلاين لتعليم الأطفال
**الفريق:** مؤسس واحد (أنت) يقوم بالتسويق + المحاسبة + متابعة الطلبة + فتح الحصص + مكالمات الأولياء
**الأدوات:** تيليجرام (حسابك + قناة الأولياء) • نظام خاص بالأولياء • نظام خاص بالمحاسبة
**اللغة الرسمية للنظام:** العربية المبسطة
**القاعدة الذهبية:** الذكاء الاصطناعي يعمل، وأنت تقرّر. لا شيء يخرج لولي أمر بدونك.

## ابدأ اليوم — 30 دقيقة

1. عبّئ الملفات في `knowledge/` (الأسعار والمستويات، الجدول الأسبوعي، الأسئلة الشائعة، سياسة الدفع).
2. أنشئ مشروع Claude باسم **«سكرتير الأولياء»**.
3. انسخ محتوى `07-prompts/01-parent-secretary.md` إلى **Instructions** في المشروع.
4. ارفع الملفات الأربعة إلى **Knowledge** في المشروع.
5. شغّل الاختبارات العشرة في `08-test-checklist.md`. **لا تستخدم الوكيل في رسالة حقيقية قبل أن ينجح في العشرة.**
